# 🎬 Movie Recommendation System

## Project Overview
A content-based Movie Recommendation System developed using Python and Machine Learning. It recommends similar movies based on genres and descriptions.

## Features
- Movie search
- Top 5 similar movie recommendations
- TF-IDF Vectorization
- Cosine Similarity
- Command-line interface

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Installation
```bash
pip install -r requirements.txt
```

## How to Run
```bash
python movie_recommendation.py
```

## Dataset
The project uses movie titles, genres, and descriptions.

## Machine Learning Technique
Content-Based Filtering using TF-IDF and Cosine Similarity.

## Purpose
Developed as an academic machine learning project.
